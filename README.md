Учёт сотрудников

Простое приложение для кадрового учёта сотрудников.

Стек
PHP, MySQL, HTML, CSS.

 Как запустить
1. Импортировать `db.sql` в MySQL (создастся база `hr_db` и таблица с тестовыми данными).
2. Проверить данные подключения в `db.php` (по умолчанию для XAMPP: логин `root`, пароль пустой).
3. Положить папку с проектом в `htdocs` (XAMPP/OpenServer) или запустить встроенный сервер `php -S localhost:8000`.
4. Открыть в браузере `index.php` (или `http://localhost/название_папки/`).

Что умеет
* *Таблица сотрудников:* вывод всех данных (ФИО, дата рождения, паспорт, контакты, адрес, отдел, должность, зарплата, дата приема).
* *Фильтры:* по отделу и должности.
* *Поиск:* по ФИО.
* *Добавление и редактирование:* создание новых карточек и изменение существующих.
* *Увольнение (Soft Delete):* сотрудник не удаляется из базы, а получает метку «Уволен». Редактирование для него блокируется.
* *Маски:* автоматический формат ввода для паспорта (`0000 000000`) и телефона (`+7 (999) 123-45-67`).

Структура проекта
* `index.php` — главная страница (вывод таблицы, поиск, фильтры).
* `form.php` — форма добавления и редактирования сотрудника.
* `fire.php` — скрипт обработки увольнения.
* `db.php` — подключение к базе данных и общие функции.
* `db.sql` — скрипт создания базы данных и тестовые данные.
* `style.css` — стили интерфейса.

Как устроена база данных
Для хранения используется таблица `employees`. 
Чтобы выполнить требование «не удалять уволенных», в таблице есть поле `is_fired` (флаг). 
Если сотрудник работает — там `0`. При увольнении скрипт `fire.php` меняет его на `1`. В `index.php` стоит проверка: если `is_fired == 1`, строка красится серым, выводится статус «Уволен», а кнопки редактирования и увольнения скрываются.

Безопасность и валидация
* Защита от SQL-инъекций: все входящие данные прогоняются через `mysqli_real_escape_string`.
* Защита от XSS-атак: вывод любых данных в HTML происходит через функцию `h()` (обертка над `htmlspecialchars`).
* Серверная валидация: проверка обязательных полей, длины паспорта и телефона происходит в `form.php` перед сохранением в БД.
