Учёт сотрудников

Простое приложение для кадрового учёта сотрудников.

Стек
PHP, MySQL, HTML, CSS.

Как запустить
1. Импортировать `db.sql` в MySQL
2. Проверить данные подключения в `db.php`
3. Положить папку в `htdocs` (XAMPP/OpenServer) или запустить `php -S localhost:8000`
4. Открыть в браузере `index.php`

Что умеет
- Таблица сотрудников
- Фильтры по отделу и должности
- Поиск по ФИО
- Добавление и редактирование сотрудника
- Увольнение: сотрудник не удаляется из базы, а получает метку «Уволен», редактировать его нельзя
- Маски для паспорта (0000 000000) и телефона (+7 (999) 123-45-67)
